Arcadia Game Hub プライバシーポリシー

最終更新日: 2026年10月29日

Arcadia Game Hub(以下「本アプリ」)は、PC にインストールされたゲームを一覧にして起動するための Windows 用ランチャーです。本アプリにおける情報の取り扱いは次のとおりです。

1. 収集・送信する情報

本アプリは、利用者の個人情報を収集しません。ゲームの一覧・インストール先・設定などの情報を、開発者や第三者のサーバーへ送信することもありません。

本アプリには、広告、アクセス解析、利用状況の計測(テレメトリー)、独自のクラッシュレポートの仕組みは含まれていません。アカウントの登録やサインインもありません。

2. PC 内で読み取る情報

本アプリは、ゲームの一覧を作るために、利用者の PC 内の次の情報を読み取ります。

  • Steam のインストール先(Windows のレジストリ)と、インストール済みのゲームの情報(ゲームの ID・名前・インストール先などが書かれた Steam の管理ファイル)
  • Steam が PC 内に保存しているゲームの画像
  • Epic Games Launcher のインストール情報(ゲームの ID・名前・インストール先などが書かれた管理ファイル。保存場所はレジストリから確認します)
  • 利用者が登録したゲームフォルダの中身(実行ファイルを見分けるためのファイル名・バージョン情報・アイコン、RPG ツクール製のゲームのタイトルが書かれたファイル)
  • 利用者が追加した実行ファイルの情報(バージョン情報・アイコン)と、利用者が選んだカバー画像

3. PC 内に保存する情報

本アプリは、次の情報を利用者の PC 内(%LOCALAPPDATA%\GameHub)にだけ保存します。

  • ゲームの名前、実行ファイルとインストール先の場所、起動引数、入手元(Steam・Epic Games・手動登録・ゲームフォルダ)、Steam・Epic Games 上のゲームの ID
  • ゲームを追加した日時、最後に起動した日時
  • 利用者が設定したお気に入り、ジャンル、プレイ状況、変更した名前、選んだカバー画像の場所
  • 利用者が登録したゲームフォルダの場所
  • Steam の画像サーバーからダウンロードしたカバー画像

保存する場所の情報(フォルダのパス)には、Windows のユーザー名が含まれる場合があります。これらの情報が PC の外に送られることはありません。

4. インターネット通信

本アプリが行う通信は、次の 1 つだけです。

  • Steam のゲームのカバー画像の取得:Steam のゲームのカバー画像が PC 内に見つからない場合に限り、Valve Corporation の画像配信サーバー(steamstatic.com)から画像をダウンロードします。リクエストの URL には、そのゲームの Steam 上の ID が含まれます。インターネット通信の仕組み上、利用者の IP アドレスは通信先のサーバーに伝わります。通信先での情報の取り扱いについては、Valve Corporation のプライバシーポリシーを参照してください。

ダウンロードした画像は PC 内に保存し、次回からはそれを使います。

5. 他のアプリとの連携

利用者がゲームを起動すると、Steam のゲームは Steam に、Epic Games のゲームは Epic Games Launcher に、そのゲームの ID を渡して起動を依頼します。その後の Steam・Epic Games Launcher の動作と情報の取り扱いは、それぞれの提供元のプライバシーポリシーに従います。

本アプリは Windows および Microsoft Store の機能の上で動作します。Windows や Microsoft Store が行う情報の取り扱い(エラー報告など)は、Microsoft のプライバシーに関する声明に従います。

6. 第三者への提供

本アプリは、利用者の情報を第三者に提供しません。

7. データの削除

保存されたデータは、利用者がいつでも削除できます。

  • Microsoft Store 版:本アプリをアンインストールすると、保存されたデータも削除されます。
  • インストーラー版:アンインストールの際に、データも削除するかどうかを確認します(既定では残します)。残したデータは、%LOCALAPPDATA%\GameHub フォルダを削除すると消去できます。
  • zip 版:%LOCALAPPDATA%\GameHub フォルダを削除すると消去できます。

本アプリの画面で個々のゲームを「登録解除」すると、そのゲームの登録情報(名前・場所・お気に入り・ジャンル・プレイ状況など)が削除されます。ダウンロード済みのカバー画像は、上記のフォルダを削除するまで残ります。また、Steam・Epic Games・ゲームフォルダから検出したゲームは、インストールされている限り、次回の検出で再び一覧に追加されます。

ゲーム本体のファイルを本アプリが変更・削除することはありません。

8. お問い合わせ

本ポリシーに関するお問い合わせは、Microsoft Store の本アプリのページに記載したサポート窓口までご連絡ください。

9. 改定

本ポリシーを改定した場合は、このページで公開します。
